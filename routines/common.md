# 공통 규칙 (모닝 브리핑 · 장 마감)

## 0. 개장일 확인
가장 먼저 저장소 루트에서 `node scripts/is-trading-day.mjs` 를 실행한다.
출력 끝이 `false`(한국거래소 휴장일)이면 **아무것도 하지 말고 즉시 종료**한다. 노션 기록·카톡 발송도 하지 않는다.

## 1. 기준 문서 읽기
- `src/lib/investTeam.js` 의 `COMMON_RULES`, `PHILOSOPHY` (오닐 × 드러켄밀러 투자 철학) — 모든 판단의 기준
- 노션 페이지 **⚙️ 투자자 프로필 (투자전략봇)** (https://app.notion.com/p/41410293caa281168fe4dce198240323) — 투자자 프로필(성향, 기간, 보유·관심 종목, 메모). Notion 커넥터로 읽는다
- 각 플레이북이 지정한 애널리스트 프롬프트와 출력 형식

## 2. 노션 (Notion 커넥터 사용)
- 데이터베이스: **📈 투자전략 리포트**
  - Data source: `collection://211805af-a065-4c71-aa4a-052bacf5ed12`
  - Database URL: https://app.notion.com/p/8c77ed355ce74fed9b115a98dcd676b7
- 속성: `제목`(title), `날짜`(date, KST 오늘), `구분`(select: `모닝 브리핑` / `장 마감`), `한줄요약`(text), `메모리`(text, 1,900자 이내), `비용USD`(number — 구독 실행이므로 0)
- 페이지 본문: 최종 리포트 전체(Markdown) → 그 아래 `---` 후 `# 부록: 애널리스트 노트` 로 각 역할의 분석 요약 → `## 출처` 에 참고한 URL 목록
- 같은 날짜·같은 구분의 페이지가 이미 있으면 새로 만들지 말고 그 페이지를 갱신한다.

## 3. 카카오톡 알림 (GitHub 자동 발송 — Claude는 호출하지 않는다)
노션 페이지를 `한줄요약` 속성까지 채워서 만들면 끝이다. 카톡은 GitHub 워크플로 `kakao-notify-poll.yml` 이
15분마다 노션 DB를 확인해 오늘자 미발송 페이지를 자동으로 보낸다(`카톡발송` 체크박스로 중복 방지).
- 메시지 형식은 워크플로가 만든다: `{아이콘} {MM/DD} {구분}\n\n{한줄요약}` (모닝 🌅, 장 마감 🌆)
- 따라서 `kakao-notify.yml` 을 실행할 필요가 없다. 카톡 발송 결과는 확인하지 않아도 된다.
- 한줄요약이 비어 있으면 발송되지 않으므로 반드시 채운다.

## 4. 실패 처리
어느 단계든 실패하면 가능한 범위에서 계속 진행하고(예: 일부 데이터 미확인 표기), 최종적으로 리포트를 만들 수 없으면
노션에 `한줄요약`이 `⚠️ {구분} 생성 실패 — {원인 한 줄}` 인 페이지를 만들어 같은 자동 발송 경로로 알린다. 페이지도 못 만들면 `PushNotification` 으로 알린다.

## 5. 금지
- 저장소 파일을 수정하거나 커밋·푸시하지 않는다. (읽기 전용)
- 특정 종목의 매수/매도를 지시하지 않는다.
- 확인하지 못한 숫자를 추정해 쓰지 않는다 — "미확인"으로 표기한다.
