# 모닝 브리핑 플레이북 (월~금 07:3x KST)

먼저 `routines/common.md` 를 읽고 그 규칙(개장일 확인 → 기준 문서 → 노션 → 카톡 → 실패 처리)을 따른다.

## 1. 연속성 기록 읽기 (노션)
- `구분 = 모닝 브리핑` 최근 5건의 `메모리` → **이미 다룬 뉴스 목록** (중복 제외용)
- `구분 = 장 마감` 최근 1건의 `메모리` → 전일 시장 상태 판정·분산일·시나리오

## 2. 분석 (웹 검색)
`src/lib/morningTeam.js` 의 `MORNING_ANALYSTS` 3개 역할을 순서대로 수행한다. 각 역할의 system 프롬프트에 적힌 관점과 출력 형식을 그대로 따른다.
1. **글로벌 매크로 전략가** (드러켄밀러) — 직전 미국·유럽 거래일, 금리·달러·원/달러 NDF·원자재·VIX, 밤사이 지표·연준 발언, 유동성 국면 판정
2. **미국 시장 방향·주도주 분석가** (오닐 M·L) — 미국 지수 분산일·시장 상태, 주도주·섹터, 한국 연관 섹터 파급
3. **신규 뉴스 스카우트** — 어젯밤~오늘 새벽 한국 시장 관련 뉴스 중 *새롭거나 기존에 없던 것*만 선별. 1단계의 "이미 다룬 뉴스"와 중복 제외. 무엇이 새로운지 명시

웹 검색은 역할당 4~6회, 전체 20회 이내로 효율적으로 쓴다.

## 3. 최종 리포트
`src/lib/morningTeam.js` 의 `MORNING_CIO` 출력 형식을 **그대로** 따른다. `(날짜)`는 오늘 날짜로 바꾼다.
한 줄 요약(`>` 줄)은 카톡에 그대로 쓰이므로 120자 이내로 핵심만.

## 4. 메모리 (노션 `메모리` 속성, 1,500자 이내)
```
[다룬 뉴스] 헤드라인 한 줄씩 (최대 10개)
[오늘 예상] 출발 방향 · 강세/약세 섹터
[유동성/미국 시장 상태] 한 줄
```

## 5. 저장·알림
`common.md` 2~3절대로 노션 페이지(`제목: YYYY-MM-DD 모닝 브리핑`, `구분: 모닝 브리핑`)를 만들고 카톡 워크플로를 실행한다.
