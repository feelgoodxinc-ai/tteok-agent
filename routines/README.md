# Claude 예약 실행(Routines) 플레이북

Claude 구독의 예약 실행이 매 개장일 아래 플레이북을 읽고 리포트를 작성합니다. (API 크레딧 미사용)

| 파일 | 실행 시각 (KST) | 내용 |
|---|---|---|
| `morning.md` | 월~금 07:3x | 모닝 브리핑 |
| `close.md` | 월~금 15:4x | 장 마감 분석 |
| `common.md` | — | 두 플레이북 공통 규칙 (노션 저장, 카톡 발송, 실패 처리) |

투자 철학·애널리스트 역할·출력 형식의 원본은 `src/lib/investTeam.js`, `src/lib/morningTeam.js` 입니다.
웹 대시보드와 같은 기준을 쓰므로, 관점을 바꾸려면 그 파일을 고치면 양쪽에 반영됩니다.

투자자 프로필(보유·관심 종목)은 비공개 노션 페이지 **⚙️ 투자자 프로필 (투자전략봇)** 에서 관리합니다 (공개 저장소에 종목 정보를 두지 않기 위함).
