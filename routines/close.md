# 장 마감 분석 플레이북 (월~금 15:4x KST)

먼저 `routines/common.md` 를 읽고 그 규칙(개장일 확인 → 기준 문서 → 노션 → 카톡 → 실패 처리)을 따른다.

## 1. 연속성 기록 읽기 (노션)
- `구분 = 장 마감` 최근 1건(오늘 이전)의 `메모리` → 전일 시장 상태, 누적 분산일, FTD 일차, 시나리오, 핵심 레벨
- `구분 = 모닝 브리핑` 오늘 날짜 1건의 `메모리` → 오늘 아침 예상 (적중 여부 복기용)

## 2. 분석 (웹 검색, 한국 증시 오늘 장 마감 기준)
`src/lib/investTeam.js` 의 `ANALYSTS` 역할을 순서대로 수행한다. 각 역할의 system 프롬프트에 적힌 관점과 출력 형식을 따른다.
1. **매크로 전략가** (드러켄밀러 유동성 국면)
2. **주도주·수급 애널리스트** (오닐 L·I — 투자주체 수급, 업종 상대강도, 신고가·거래량)
3. **시장 방향 분석가** (오닐 M — 분산일 카운트는 1단계 전일 기록을 이어받아 갱신, 팔로스루데이, 시장 상태 판정)
4. **실적·촉매 애널리스트** (오닐 C·A·N, 향후 5거래일 이벤트)
5. **포트폴리오 애널리스트** — 노션 투자자 프로필에 보유·관심 종목이 있을 때만 (CAN SLIM 체크, -7~8% 손절선)

웹 검색은 역할당 3~5회, 전체 25회 이내로 효율적으로 쓴다.

## 3. 리스크 검토
`investTeam.js` 의 `RISK_SYSTEM` 임무대로 위 분석을 스스로 레드팀 검토한다 (수치 충돌, 근거 부족, 오닐/드러켄밀러 경고 신호, 두 관점 충돌).

## 4. 최종 리포트
`investTeam.js` 의 `CIO_SYSTEM` 노출 기준과 출력 형식을 **그대로** 따른다.
"3. 전일 전망 복기"에는 전일 장 마감 기록과 **오늘 아침 모닝 브리핑 예상**의 적중 여부를 모두 다룬다.
한 줄 요약(`>` 줄)은 카톡에 그대로 쓰이므로 120자 이내로 핵심만.

## 5. 메모리 (노션 `메모리` 속성, 1,500자 이내)
```
[시장 상태(오닐)] 판정 + 지수별 누적 분산일 수 + FTD/반등 시도 일차
[유동성 국면(드러켄밀러)] 판정
[권장 주식 비중] 범위
[내일 시나리오] Base/Bull/Bear 확률과 트리거 한 줄씩
[핵심 레벨] 지수 지지/저항
```

## 6. 저장·알림
`common.md` 2~3절대로 노션 페이지(`제목: YYYY-MM-DD 장 마감`, `구분: 장 마감`)를 만들고 카톡 워크플로를 실행한다.
